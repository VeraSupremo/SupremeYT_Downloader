# SupremeYT_Downloader
App to download music from youtube in mp3 and videos in mp4






La app esta realizada sin ninguna intencion de Lucro, solo se busca solventar una necesidad hallada.
App solo para windows.
- Requisitos para el uso de la app:
- Tener Instalado el ffmpeg para que la conversion de la musica a mp3 se realice correctamente
- tener conexion a internet
